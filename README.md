# Arete

Arete(ah-reh-tee), the Greek word for excellence, is a fabric utility client for version Minecraft 1.21.5. 


## How It's Made:

**Tech used**: Java, NanoVG, Fabric API



### Throughout this project, I explored:
* Custom 3D Rendering
* Custom 2D Text rendering Via NanoVG
* Gui Design and modular interface system
* Asset Caching

### Features
* Rotation System which simulates movement to bypass [GrimAC](https://github.com/GrimAnticheat/Grim)
* Custom font system powered by NanoVG, which utilizes all available system fonts
* Modern GUI powered by NanoVG for high-performance vector rendering
* Custom 3D rendering system featuring smooth, fluid animations
